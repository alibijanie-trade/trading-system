### هدف اصلی: `binance_client.py` (REST wrapper)

این اولین component واقعی فاز ۱ است. مسئولیت‌ها:

1. **REST API wrapper** برای Binance Spot
   - Public endpoints: klines، ticker، orderbook
   - Authenticated endpoints: account info، open orders، place/cancel order
   - Rate limiting (Binance: 1200 req/min vanilla، WS برای real-time بهتر)
   - Retry logic + exponential backoff
   - Error handling: HTTP errors، Binance-specific error codes

2. **Integration با CCXTDataSource موجود**
   - `backend/datasource/ccxt_source.py` از چت ۱۰ موجود است
   - `binance_client.py` می‌تواند به‌عنوان BinanceDataSource خاص‌تر باشد
   - یا standalone برای موارد خارج از CCXT abstraction (مثلاً WS که CCXT خوب پشتیبانی نمی‌کند)

3. **Tests**
   - `backend/tests/test_binance_client.py` — pytest
   - Mock Binance API responses
   - بخش‌های authenticated با fixtures

4. **Documentation**
   - Docstrings (Sphinx style)
   - مثال‌های استفاده در docs/

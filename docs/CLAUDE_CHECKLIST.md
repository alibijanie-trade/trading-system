## اصول

1. این چک‌لیست **اجباری** است، نه پیشنهادی.
2. هر مرحله باید **explicitly** انجام و در ذهن Claude (نه فقط implicit) چک شود.
3. اگر مرحله‌ای **نمی‌توان** انجام داد، Claude **توقف می‌کند** و گزارش می‌دهد.
4. ترتیب مراحل **متوالی** است. پرش به جلو ممنوع.
5. این چک‌لیست در **PROJECT_GOVERNANCE.md بخش ۴ و ۵** ارجاع داده شده.

## فاز ۲ — چک‌لیست در حین کار (per-task)

این چک‌لیست **در هر گام کاری** اجرا می‌شود.

### قبل از تولید اسکریپت

```
[ ] آیا قبل از نوشتن، فایل‌های فعلی را خواندم؟
[ ] آیا قانون #۲۲ را به یاد دارم؟ (نیاز به اسکریپت تست همراه)
[ ] آیا اسکریپت idempotent خواهد بود؟
[ ] آیا Anti-Pattern های A1-A10 را در نظر دارم؟
```

### حین نوشتن کد (frontend)

```
[ ] هیچ hex hardcoded ندارم؟
[ ] از CSS variables استفاده می‌کنم؟
[ ] اگر variant: کانتینر از تم + accent باریک (سند ۸.۸.۱)
[ ] Interactive states (hover/active/focus-visible/disabled) رعایت شد؟
[ ] از rem نه px برای fontSize استفاده می‌کنم؟
[ ] ARIA attributes برای accessibility دارم؟
```

### حین نوشتن کد (backend)

```
[ ] Query از Repository می‌رود نه مستقیم از DB؟
[ ] هیچ hardcode در .env-able value ندارم؟
[ ] # -*- coding: utf-8 -*- در ابتدای فایل Python؟
[ ] Exception handling مناسب؟
[ ] Logger به جای print؟
```

### قبل از تحویل اسکریپت

```
[ ] اجرا کردم محلی (در محیط Claude)؟
[ ] تست idempotency (اجرای دوم بدون خطا)؟
[ ] تست خودکار pass شد؟
[ ] خروجی مثال انتظاری دارم؟
[ ] دستور اجرا با نام tab صحیح (🟦/🟩/🟧)؟
```
